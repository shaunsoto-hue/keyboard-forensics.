What can be recovered?

Named keys: when a visible text field changes, the app compares OCR text between frames and can report characters such as A, 7, or ?, plus inferred Backspace/Enter in some cases.

Action timeline: the analyzer looks for visible text edits, masked-password character changes, backspaces, screen/UI changes, and keyboard-like audio transients. It also records basic video metadata such as duration, dimensions, and file type.

Limit: if the pressed key leaves no observable evidence in the recording, no website can reliably reconstruct the original keyboard event from the video alone. Results are inferences, not a hidden Chromebook key log.
